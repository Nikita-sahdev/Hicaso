## How a project runs, in four steps

### Pick the features to build first

We learn your goals, users and limits, and write down the first release with you.

### Design the product with you

Flows and screens are agreed before any code, while a change still costs little.

### Build the software, with a weekly demo

We build in short cycles, and you try working software in a demo each week.

### Launch, then support and improve

We release to production or the app stores, then fix and improve. The code and IP are yours.
