## /services/generative-ai

# Generative AI for product teams

Our team in India adds generative AI to your product or builds new ones around it: assistants, retrieval over your own data, and the checks that keep outputs useful.

Start a project. See all services.

## What we build in generative AI

### Adds AI features to your product

Summaries, search, drafting or classification in the app you already run.

### Answers questions from your documents

Retrieval over your files and databases, so each answer comes from your data.

### Checks model output before release

Test sets and checks measure output quality and keep the model inside its limits.

## Questions

Do I own the code? Yes. Once the project is paid for, the code and IP are yours.

Which model will you use? We pick the model that fits your task, data and constraints. That can be a hosted model or an open-source one.

Can the AI work with our private data? Yes. Retrieval can run over your own documents and databases, and we agree on how that data is handled before we start.

## Tools for generative AI

Models and frameworks: OpenAI, Claude, Gemini, open-source LLMs, LangChain and LlamaIndex.

Vector search: pgvector and Pinecone. Backend: Python and Node.js.

## /services/agentic-ai

# AI agent development for teams

Our team in India builds AI agents that call your APIs and tools and carry a task through several steps. A person approves the actions you choose, and every run is traced.

Start a project. See all services.

## What we build in agentic AI

### Connects AI agents to your tools

Agents read from and act on the systems your team already works in, through APIs and MCP servers.

### Asks a person to approve AI actions

Approval steps put a person in front of each action you choose.

### Shows what each AI agent run did

Traces and evaluations show how an agent behaves and catch regressions.

## Questions

Do I own the code? Yes. Once the project is paid for, the code and IP are yours.

Can an agent act without approval? Only where you decide it can. We add approval steps for actions that need a person.

How do we know what the agent did? We can log each step and tool call so runs can be reviewed and evaluated.

## Tools for agentic AI

Agents and protocols: Claude Agent SDK, OpenAI Agents SDK, LangGraph and MCP.

Backend: Python and Node.js.
